# 고정 검사

> 이 파일은 작업 시작 전에 고정한다. 커밋 이후 **어떤 이유로도 수정하지 않는다.**
> 검사 삭제·완화·기대값 변경은 0건이어야 한다. AI는 코드를 고쳐서 검사를 통과시켜야 한다.
> 실행 기록·해시·시각 등 변하는 정보는 `tests/records.md`에 남긴다.

## 1. 개선 기능
**이미지 입력 경로 확장** (기능 1개)
- 기존 클릭 업로드 외에 배경 이미지를 넣는 경로를 늘린다.
  - 경로 1: 클립보드 붙여넣기(Ctrl+V)
  - 경로 2: 드래그앤드롭
- 두 경로 모두 기존 업로드 검증(이미지 형식 확인·오류 안내)을 재사용한다.
- 검사 담당 구분: CHK-01~05는 경로 1, CHK-06~10은 경로 2.

- 시간 상한: **AI당 60분** (첫 프롬프트 전송 시각부터 종료 선언 시각까지의 경과 시간)
- 요청·호출 수 상한: **AI당 15회** (프롬프트 전송 횟수. 재생성·수정 요청도 각각 1회로 센다)

## 4. 준비 파일 (`tests/fixtures/`)
`test1.png`, `test2.png` (서로 다른 이미지), `test.txt` (이미지 아님)

## 5. 고정 검사 10개

| ID | 담당 | 입력 | 기대값 |
|---|---|---|---|
| CHK-01 | 경로 1 | `test1.png`를 우클릭 → 이미지 복사. 편집기 빈 곳을 클릭한 뒤 Ctrl+V | 캔버스 배경에 `test1.png`가 표시된다 |
| CHK-02 | 경로 1 | 이미지가 로드된 상태에서 문구 입력창에 포커스를 두고, 텍스트 "안녕"을 복사해 Ctrl+V | 입력창에 "안녕"만 붙고 배경 이미지는 그대로다 |
| CHK-03 | 경로 1 | 클립보드에 텍스트만 있는 상태에서 문구 입력창 밖에 포커스를 두고 Ctrl+V | 배경·문구에 변화가 없고 오류 안내도 뜨지 않는다 |
| CHK-04 | 경로 1 | `test1.png`를 클릭 업로드로 로드하고 `test2.png`를 이미지 복사해 둔다. 문구 입력창에 "테스트" 입력 → 굵게 켜기 → 글자 크기 슬라이더 조절 순으로 한 뒤, 다른 곳을 클릭하지 않고 바로 Ctrl+V | 배경만 `test2.png`로 바뀌고 문구·굵게·글자 크기는 유지된다 |
| CHK-05 | 경로 1 | CHK-04 직후 문구 입력창 밖 포커스에서 Ctrl+Z | 배경이 `test1.png`로 돌아온다 |
| CHK-06 | 경로 2 | `test1.png`를 업로드 영역에 드래그앤드롭 | 캔버스 배경에 `test1.png`가 표시된다 |
| CHK-07 | 경로 2 | 이미지가 로드된 상태에서 `test.txt`를 업로드 영역에 드롭 | 오류 안내가 표시되고 기존 배경은 유지된다 |
| CHK-08 | 경로 2 | 이미지가 로드된 상태에서 `test1.png`와 `test2.png`를 동시에 드롭 | "한 번에 한 장만 가능" 취지의 안내가 표시되고 배경은 변하지 않는다 |
| CHK-09 | 경로 2 | 파일을 끌고 업로드 영역 위로 진입했다가 영역 밖으로 벗어남 | 진입 중에는 테두리가 강조색(보라)으로 바뀌고, 벗어나면 원래 회색 점선으로 돌아온다 |
| CHK-10 | 경로 2 | 배경이 있는 상태에서 다른 이미지를 드롭한 뒤 문구 입력창 밖 포커스에서 Ctrl+Z | 배경이 이전 이미지로 돌아온다 |

- 오류 안내는 문구가 아니라 **표시 여부**만 본다.
- 실행할 때마다 10개 전체(CHK-01~10)를 함께 확인한다.

## 6. 최초 요청 (AI A·AI B 공통 기능 설명)
> 이 저장소는 이미지+문구를 합성하는 웹 편집기(HTML/CSS/JS, 빌드 도구 없음)다.
> 기능 "이미지 입력 경로 확장"을 완성하라. 배경 이미지를 클릭 업로드 외에 붙여넣기(Ctrl+V)와 드래그앤드롭으로도 넣을 수 있게 한다.
> 규칙: (1) `tests/checks.md`의 검사는 수정하지 말고 코드만 고쳐 통과시킬 것. (2) 기존 업로드 검증을 재사용할 것. (3) 기존 파일 구조(js/ 아래 모듈 분리)를 유지할 것. (4) 기존 기능이 깨지지 않게 할 것.
